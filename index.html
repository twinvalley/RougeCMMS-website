🔧 RougeCMMS

Computerized Maintenance Management — offline-first, portable, free.

Manage assets, work orders, PM schedules, inventory, BOMs, vendors, and purchase orders — all in a single desktop app. Git-backed version control, kanban boards, and a background service for scheduled reports.

  • 📋 Work Orders & Kanban
  • 🔁 PM Schedules with Kit Libraries
  • 📦 Inventory & Reorder Tracking
  • 🏗️ Asset BOM (bill of materials)
  • 🚚 Vendors, POs & Receiving
  • 📊 Scheduled Reports & CSV Import
  • 🔍 Global Search & Command Palette
  • 🔐 Role-based Access (Admin / Tech)
  • 📝 External Maintenance Reports API
  • 💾 Git-backed DB version control
  • 🖥️ Portable mode (USB / removable drives)
  • 🔔 Notification Center with Rules
